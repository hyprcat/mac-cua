## Codebase Patterns
- Build/test from the `swift/` dir: `cd swift && swift build && swift test`. Toolchain: Swift 6.x.
- `MacCUACore` + `MacCUAServer` are **Linux-pure**: NO macOS framework imports (no AppKit/CoreGraphics/ApplicationServices/ScreenCaptureKit/Vision/IOKit). All macOS code goes in `MacCUAKit`/`CSkyLightShim`/the executable behind `#if os(macOS)`.
- Port behavior from the Python reference in `app/` + `app/_lib/`; match the existing test intent.
- Provider protocol seams are already defined in `swift/Sources/MacCUACore/Providers.swift` — Phases 3–6 implement them in `MacCUAKit`.
- **Prime Invariant:** never foreground / activate / warp-cursor / global-post. Banned symbols are guarded by story US-012; never weaken those guards.
- Target the **experimental confirmed-delivery pipeline** (transport-confirm via delivery tap + snapshot-as-truth + `compute_verdict`). Do NOT re-enable inline post-delivery AX verification on primary paths (Invariant 21).
- Exact SPI symbols + CGEvent field numbers: `docs/CODEX_PARITY_CHANGES.md` Appendix. The 23 invariants: `docs/SWIFT_PORT_DESIGN.md` §3.
- **Speed:** decompose each story and run Sonnet/Opus sub-agents in parallel (read Python / draft Swift / write tests / audit invariants).

## US-043 — Retries + circuit breaker (SCK failure counter actor)
- `withRetry`/`RetryPolicy` (+ axRetry/screenshotRetry/eventRetry policies) were already ported in `Sources/MacCUACore/Retry.swift` (US earlier). The gap was the SCK circuit breaker from `screen_capture.py` `ScreenCapturer` (`_consecutive_failures`/`_circuit_open_until`, threshold 2, cooldown 30 s).
- New `Sources/MacCUACore/CircuitBreaker.swift` (Linux-pure, Foundation only): `CircuitBreakerState` (time-INJECTED pure value type — `shouldAttempt(now:)` / `recordSuccess()` / `recordFailure(now:)`, matches the DebounceStateMachine injection style) + `CircuitBreaker` thread-safe wrapper (`@unchecked Sendable` + NSLock — the "failure counter actor": serialized, Sendable, but SYNCHRONOUS so it drops into the sync `captureWindow` path with no async ripple; injected `now` defaults to `ProcessInfo.systemUptime`, Linux-available).
- Wired into `KitCaptureProvider.captureWindow`: `sckBreaker.shouldAttempt()` gate at top (tripped+cooling → skip SCK → `privateFallbackImage` directly); `recordFailure()` on the two SCK failure exits (shareableWindow nil, captureImageSync nil); `recordSuccess()` on a delivered SCK frame. `sckBreaker` stored on the provider (Stubs.swift class def).
- Tests: `Tests/MacCUACoreTests/CircuitBreakerTests.swift` (8 cases: fresh attempts, below-threshold still attempts, trips+bypasses-during-cooldown, probe-after-cooldown, success-resets, probe-failure-rearms, threshold-1-immediate, wrapper drives injected clock).
- Sub-agents used: none — contained pure-logic + 3-line Kit wiring story; full context from reading retry.py/screen_capture.py + KitCaptureProvider directly.
- Quality gate: macOS `swift build` clean; `swift test` 774 passed / 0 fail (+8).
- MANUAL-VERIFY PENDING: see Manual-Verify Backlog [US-043].
- Learnings: the "counter actor" requirement is best served by a sync NSLock-backed `@unchecked Sendable` class, NOT a real `actor`, because the capture path (`captureWindow`) is synchronous (CaptureProvider protocol) and an actor would force an async ripple through the whole capture seam. Keep the breaker STATE pure + time-injected in Core (testable on Linux) and let the wrapper own the clock — same split as DebounceStateMachine. Probe semantics: once cooldown expires, `shouldAttempt` returns true even though failures still ≥ threshold; a probe failure re-arms `openUntil` from the new now; only `recordSuccess` zeroes the counter.

## US-004 — Request/turn-scoped cache (L1) in Core
- Implemented `swift/Sources/MacCUACore/TurnCache.swift`: a reference-type `TurnCache` with one-turn/batch lifetime porting apps.py's `_pid_cache`/`_ax_app_cache`/`invalidate_caches_for_pid`. - Sub-agents used: none — small contained pure-logic story done directly in main thread (matches US-001..003 sizing).
- Quality gate: `swift build` clean; `swift test` 393 passed / 0 fail (was 385).
- Learnings: model L1 as a reference type (reuse within a turn IS the point) and inject liveness rather than importing a macOS pid check — keeps Core pure. Eviction-on-dead-pid happens lazily at read time (matches apps.py validate-before-reuse) rather than eagerly. Keep two invalidation granularities: full `invalidate(pid:)` for app-identity changes and `invalidateTree(pid:)` for the common post-action re-walk so the batch (US-008) doesn't re-resolve the app each step.

## US-005 — select_text range-resolution (D1 pure tier) in Core
